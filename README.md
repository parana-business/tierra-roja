# tierra-roja
Estudio de Arquitectura

Sitio web de **Tierra Roja Arquitectura** — arquitectura contemporánea en Posadas, Misiones.

Sitio estático (HTML + CSS + JS, sin build). Listo para GitHub Pages: `Settings › Pages › Deploy from a branch › main / (root)`.

## Estructura
- `index.html` — página principal
- `styles.css` — estilos
- `app.js` — menú, animaciones, carrusel de proyectos y fichas de proyecto
- `assets/images/` — fotografías
